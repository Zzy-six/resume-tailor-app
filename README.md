# 简历定制助手 Pro

类小程序形态的简历定制工具（PWA），纯前端、免后端、免费使用。上传简历 + 招聘要求（文字/图片/文档），自动识别岗位方向、分析技术栈匹配度，一键生成针对性的定制简历。

## 功能特性

- **类小程序体验**：PWA 单页应用，可安装到桌面/手机桌面，离线可用（Service Worker 缓存）
- **本地文件直接访问**：点击按钮打开系统文件选择器，或直接选择整个文件夹导入，支持拖拽上传
- **图片 / 文档免 OCR 依赖**：招聘要求支持图片（Tesseract OCR 自动识别）、PDF、Word（docx 文本提取）
- **岗位方向自动识别**：从招聘要求文本中自动识别开发 / 测试 / 算法 / 运维 / 前端 / 后端等岗位类型，无需手动选择
- **AI 重写两种模式，无 API 也能用**：
  - 本地 AI（默认）：基于 Transformers.js 在浏览器内运行小模型（Qwen2.5 等），全程免 Key、免费、数据不出浏览器
  - 云端 AI（可选）：填写任意 OpenAI 兼容 API（Base URL / Key / 模型）获得更强结果
- **匹配分析**：JD 技术栈命中 / 缺失 / 额外技能可视化，附带优化建议
- **一键输出**：Markdown 定制简历，支持复制与下载

## 本地使用

直接双击打开 `index.html`，或者起本地服务：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 部署到 GitHub Pages

1. 把本目录推送到 GitHub 仓库
2. 仓库 Settings → Pages → Source 选择 main 分支根目录
3. 等待几分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

或者 fork 本仓库后直接开启 Pages。

## 隐私说明

所有数据（简历、图片、招聘要求）只在浏览器本地处理。本地 AI 模式加载模型时需联网下载模型文件，处理过程不离开浏览器。
